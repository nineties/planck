Planck
======

Planck is a programming language for symbolic processing and language processing.

* Metaprogramming with few limits: a program can extend the language itself.
* Partial functions, their fusion, and pattern matching are at its core.
  A function takes its arguments by patterns, and fusing two functions makes
  one that tries the first and then the second.
* It continues the `hex-to-compiler <https://github.com/nineties/hex-to-compiler>`_
  project. It starts from hand-written machine code and is built without any
  other language implementation.
